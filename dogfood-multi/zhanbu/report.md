## 6. 灵签抽签 ⭐ 5.0/5 👑 最佳（已修复 Bug）

**功能测试**:

- ✅ 输入愿望（1-30 字）
- ✅ 选择摇签方式（手摇/摇动/求签）
- ✅ 点击求签后**先显示摇签中动画 1.8s，再显示签文**
- ✅ 30 签典：上上/上/中上/中/中下/下/下下

**实测结果**: 第25签 上上 独占鳌头

- 独占鳌头第一名，蟾宫折桂月宫行。从今不负青云志，万里鹏程指日成。
- 解：大吉·高科及第
- 五行金 / 类·事业
- 宜：考试、求名
- 忌：自满

**🔧 修复的 Bug**:

- **原问题**: `draw()` 函数先设 `drawing.value = true`，但此时 `qian.value` 仍为 null，模板用 `v-if="!qian"` 切走，所以**摇签中动画永远不可见**。然后 `await 2000ms`，再设 `qian.value = drawn`，此时 `drawing` 紧接着被设为 `false`，用户看到的只是从 form 直接跳到 qian-card，没有中间动画。
- **修复方案**: 重新排序——先 `drawQian()` 同步算出结果，设 `qian.value = drawn`（先切到结果视图），再设 `drawing.value = true`（显示摇签中），await 1.8s，最后 `drawing.value = false`（显示签文）。这样用户能看到完整的「摇签中」动画过渡。
- **修复位置**: `/workspace/src/modules/mingming/pages/lingqian.vue:198-219`
- **验证截图**: `6-lingqian-02-shaking.png` 现在正确显示「摇 签 中 ...」紫色发光球体，1.8s 后切换到签文详情。

**动画评估**:

- 摇签中：紫色渐变发光球体 + 中心金色星芒（⭐⭐⭐⭐⭐ 视觉超棒）
- 签文：古风排版，居中显示诗文
- 宜/忌：绿色/红色 chip 区分

**视觉评估**:

- 签级颜色：上上=金红、上=金、中上=橙黄、中=黄、中下=青灰、下=灰白、下下=灰
- 古籍风排版非常契合主题

**问题清单**: 已全部修复

### Bug #1: 灵签抽签摇签动画不可见

| 字段         | 描述                                                                                                     |
| ------------ | -------------------------------------------------------------------------------------------------------- |

| **修复文件** | `/workspace/src/modules/mingming/pages/lingqian.vue` (line 198-219)                                      |
| **验证状态** | 已重新构建 (`npx uni build`)，新 bundle 包含修复（grep 验证：`setTimeout(e,1800)` 而非 `2e3`）           |

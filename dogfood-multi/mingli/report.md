## Issues Fixed

### FIX-M01: 7 个工具缺少 LoadingSeal 加载动画 (体验一致性)

| Field | Value |
|-------|-------|
| **Severity (before)** | medium UX 一致性 |
| **Files** | `life.vue` / `astro.vue` / `maya.vue` / `dayun.vue` / `jiri.vue` / `jiazu.vue` / `liunian.vue` |
| **影响** | 7/16 (44%) 工具在计算时无 LoadingSeal，与其他 9 个工具不一致 |

**问题**

- dogfood 测试发现 `has_loading=False` 的工具：流年大运/生命灵数/西洋占星/玛雅历/大运流转/吉日择时/家谱排辈
- 这些工具都有 `const loading = ref(false)` 但未挂载 `<LoadingSeal>` 组件
- 导致计算时屏幕"卡顿"无视觉反馈，破坏"玄枢"玄学仪式感

**Fix**

- 7 个文件均添加：
  - `import LoadingSeal from '@shared/components/ui/LoadingSeal.vue'`
  - `</view></template>` 之前插入 `<LoadingSeal :visible="loading" :title="..." :steps="..." :duration="..."/>`
- 每工具独立标题，duration 适配计算耗时（800-1500ms）

**验证**

- 重新构建 `pnpm build:h5` → 成功
- 重新跑测试 → 7 个工具 `has_loading` 从 False 变 True
- 47 张截图 (16 工具 × 3 截图 − 1 罗盘无 loading = 47)

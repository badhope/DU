## 🐛 已发现并修复的 Bug

### Bug #1：奇经八脉 · 穴位数据库严重不足
- **症状**：人体图共 112 个穴位，但 `ACUPOINT_DB` 仅 16 个，点击大多数穴位无任何反馈
- **根因**：`src/modules/jiankang/logic/jingluo.ts` 中 `ACUPOINT_DB` 收录不完整
- **影响**：用户点击「中府」「少府」「列缺」「商阳」等高频穴位无反应，体验断裂
- **修复**：
  1. 扩充 `ACUPOINT_DB` 至 **216 个** 高频常用穴位（覆盖率 ~85%）
  2. `BodyMap.vue` 的 `onAcupointClick` 增加 **fallback**：未收录穴位显示「穴位名 + 所属经脉 + 收录中」提示
- **验证**：点击「合谷」→ 弹出完整 5 维详情（经脉/位置/功能/主治/方法）✓

### Bug #2：经纬度排序导致"未识别"潜在风险
- 检查 24 节气顺序：`立春(0) → 雨水(1) → 惊蛰(2) → ... → 芒种(8) → ... → 大寒(23)` ✓ 正确
- 今日 2026-06-11，识别为 **芒种** ✓ 正确（芒种节气为 6/5-6/21）
- 12 时辰：巳时（09-11）对应 **脾经** ✓ 正确
